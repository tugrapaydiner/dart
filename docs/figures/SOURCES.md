## Published numbers (each system's own paper/release — own hardware, models,
tasks; a positioning landscape, not a controlled head-to-head).
Last verified against the sources: **2026-07-05.**

- **EAGLE-3**: lossless speculative decoding, speedups 3.27–6.47× across
  models/benchmarks (peak used in figures: 6.47×). arXiv:2503.01840.
- **DFlash**: block-diffusion drafting + AR verification, lossless; >6×
  across models/tasks, 4.86× avg / 6.08× peak single-user on Qwen3-8B
  (peak used: 6.08×), reported up to 2.5× over EAGLE-3. arXiv:2602.06036.
  (A June 2026 press report claims 15× on Blackwell-generation hardware;
  vendor-optimized and not in the paper, so not plotted.)
- **VeriCache**: compressed-KV drafting verified against full KV, *identical
  outputs*; up to 4× vs full-KV inference on long-context decoding (peak
  used: 4.00×; an earlier draft reported 3.82×). arXiv:2605.17613.
- **DiffusionGemma**: 26B-MoE open text-diffusion model (3.8B active),
  standalone generation up to 4× faster than AR — LOSSY (below Gemma 4
  quality per Google). Google DeepMind release, 2026-06-10.
- **KIVI**: 2-bit KV quantization, 2.35–3.47× throughput (peak used:
  3.47×) — LOSSY (no verification). ICML 2024.

## DART's own numbers (measured in this repo)

- 100% exact greedy match: CPU suite + CUDA/gpt2 run, gated per benchmark
  row (`benchmarks/results/gpu_bench_rtx5060.md`, `cpu_bench_tiny.md`).
- Reconciliation: +55% ± 8% accepted-tokens-per-diffusion-forward (mean ±
  sample std over 5 prompt seeds, min +46%), identical drafter weights per
  arm (`benchmarks/results/reconciliation_ablation.md`).
- Exactness vs bits: unverified quantized decode falls 0.92 → 0.00 from
  8 → 2 bits while the verified path stays 1.000
  (`benchmarks/results/exactness_vs_bits.md`).
- KV reduction: 71% at 128K for the stated 27B-class config (exact byte
  accounting including fp32 scale/zero overhead).
- Measured best lane: 2.20× wall-clock (ngram, gpt2 fp32, RTX 5060 Laptop
  GPU, single run; `benchmarks/results/gpu_bench_rtx5060.md`).
- Projected ceiling ~5×: batch-1 roofline projection, always drawn hatched
  and labelled as projected, never reported as measured.

DART is an acceleration layer, not a chat model; it is never compared to
hosted chat models on answer quality (a category error — DART reproduces a
chosen target's output, including open models'). vLLM/TensorRT-LLM (the
stacks behind production serving) ship the benchmarked methods:
n-gram/EAGLE/diffusion spec decoding.
